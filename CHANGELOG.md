# Changelog

All notable changes to the claude.md template will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2025-01-15

### Added - User-Friendly Edition
- Complete redesign focused on ease of use
- Quick Start section (fill out in 5 minutes)
- Progressive disclosure approach
- Multiple choice options (delete what you don't use)
- Checkboxes for tracking completion
- Real examples throughout (not just placeholders)
- FILL_OUT_GUIDE.md for step-by-step instructions
- MIGRATION_GUIDE.md for adding to existing projects
- ADVANCED.md with power user techniques
- FAQ.md with common questions and answers
- CONTRIBUTING.md for open-source contributions
- QUICK_REFERENCE.md as a bookmark-able cheat sheet
- example.claude.md showing a filled-out template
- .env.example template
- LICENSE (MIT)
- Progressive complexity guide for AI assistants
- "When to update" guidance
- Better organization with clear section priorities

### Changed - Breaking Changes
- Restructured entire template (v1 users need to migrate)
- Changed from comprehensive-first to quick-start-first
- More conversational, less formal tone
- Fewer mandatory sections
- More emphasis on practical examples
- Better separation of essential vs. optional content

### Improved
- All sections now have concrete examples
- Clearer instructions throughout
- Better guidance on what to include/exclude
- More beginner-friendly language
- Reduced overwhelm for new users
- Better suited for projects at all stages

## [1.0.0] - 2024-12-01

### Added - Initial Release
- First version of claude.md template
- Comprehensive coverage of all aspects
- Vite + Supabase focused
- Basic README documentation
- Example patterns and conventions

### Known Issues
- Too comprehensive for beginners
- Hard to know where to start
- Too many empty placeholders
- Not enough concrete examples
- Unclear what's essential vs. optional
